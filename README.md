# Project 7 — Intent Classification for a Smart FAQ Chatbot

## Project scope

This implementation follows the assignment requirements: at least six intents, labeled example messages, text preparation, TF-IDF features, two classification models, held-out evaluation, response mapping, confidence-based fallback, saved model artifacts, and a Streamlit chat interface.

The custom dataset covers 15 intents: greeting, course enquiry, syllabus, admission process, registration, admission documents, admission deadline, fees, fee payment, fee receipt, technical login, password reset, technical issue, contact information, office hours, and goodbye.

```bash
python3 -m venv .venv

python -m pip install --upgrade pip

```

## Train and evaluate

```bash
python train_model.py
```

The script:
- inspects and cleans the dataset,
- uses a stratified held-out test split,
- fits word-level and character-level TF-IDF within each pipeline,
- trains Multinomial Naive Bayes and Logistic Regression,
- reports accuracy, macro precision, macro recall, macro-F1, weighted-F1, classification reports, and confusion matrices,
- selects the best model by held-out macro-F1,
- saves the model, FAQ responses, metadata, model comparison, and misclassified examples.

## Launch Streamlit

```bash
streamlit run app.py
```

Click sample questions or type your own message. The sidebar lets you adjust the fallback confidence threshold.

## Realistic FAQ answers

Responses are written as practical guidance for each predicted intent. Institution-specific facts such as actual fee amounts, application deadlines, office hours, email addresses, and phone numbers are deliberately not invented. Replace or supplement `data/faq_responses.json` with verified information from the relevant institution. Re-run training to copy the updated response mapping into `models/`.

## Model details

Two models are compared using a common split:
1. Multinomial Naive Bayes
2. Logistic Regression

The feature pipeline combines word TF-IDF unigrams/bigrams with character TF-IDF n-grams. This can help capture both phrase meaning and spelling variation. The vectorizers are fitted only on training data through Scikit-learn pipelines, avoiding test-data leakage.

## Limitations

- The included dataset is a custom starter dataset, not a large real-world conversational corpus.
- The held-out test set is small. Results may vary, and strong scores on these examples do not guarantee accuracy on real user messages.
- A probability threshold is only a basic uncertainty check; model confidence is not guaranteed to be calibrated, and unsupported messages can still receive high scores.
- Intent classification chooses a label; the response is selected from a predefined mapping. It is not response generation.
- Do not use the generic answers as official institutional policy without verification.

## Workflow

User message → word and character TF-IDF → classifier → confidence threshold → intent-specific predefined answer or fallback.
